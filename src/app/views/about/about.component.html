Explorador de API do sistema Ponto System Web

Esta aplicação foi desenvolvida como apoio à integração com a API de Consulta do sistema Ponto System Web.

Seu objetivo é facilitar o trabalho dos integradores, oferecendo:

  • 🔍 Visualização dos Endpoints disponíveis na API;
  • ⚙️ Exploração de Parâmetros, com possibilidade de modificação em tempo real;
  • 📄 Visualização das Respostas retornadas pela API;
  • 💡 Exemplos práticos de como realizar requisições para cada endpoint.

ATENÇÃO Para chamar os endpoints da API nesta aplicação, é preciso antes fazer a autenticação usando a chave fornecida pelo suporte técnico.
Para autenticar basta clicar no botão que se encontra no topo a direita.

ATENÇÃO Esta aplicação não é um sandbox. Os dados aqui apresentados são os dados reais da licença.

ATENÇÃO Esteja ciente que o uso indevido desta API pode acarretar na inativação do token de autenticação.
