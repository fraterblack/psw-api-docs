Importa registros de forma síncrona. O corpo da requisição deve ser uma lista (array) com no mínimo 1 e no máximo 10 objetos, cujas chaves são os códigos (code) dos dados aceitos na importação. Listas fora desse limite são rejeitadas por completo (status 400).

Os dados aceitos são retornados pelo endpoint [GET] {{ selectedEndpoint.service }}{{ selectedEndpoint.importFieldsPath }}

A resposta (status 200) é uma lista com o resultado de cada registro, na mesma ordem da lista enviada: index (posição do registro, iniciando em 0), status (added: registro criado; duplicated: registro já existente; invalid: registro não importado por erro), id (ID do registro criado, quando added) e message (motivo da falha, quando invalid). A falha em um registro não impede a importação dos demais.
